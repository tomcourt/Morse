This trainer will teach you morse code quickly. It has the following conventional features to do this:

  • Farnsworth method - play morse code characters quickly while allowing more time between characters and words to respond
  • Koch method - start by mastering 2 characters before adding more 2 at a time and then mastering those
And a number of new features that also help you learn quickly:
  • Quick feedback - a buzzer sound immedietly indicates the character was wrong or wasn't typed in time
  • Balanced training - additional lessons concentrating on problem characters make sure all characters are learned equally well
  • Detailed graphs - for each character shows both accuracy and speed of recognition
  • Visual progress - your progress is clearly shown in graphs to assist with motivation

Usage:

To start or stop a lesson, click on the player control symbol or press Esc key.

Characters sent show up in the large result box. Black for correct, red for wrong, orange for timeout.

To see the morse for any character, hover the cursor over the character in the graph below. To hear it, click on the character.

Tips:

Remember to clearly think of the character while typing it, otherwise you are training

your fingers to move when you hear a sound and will have trouble handwritting or hearing the words later.

To practice characters you are having trouble telling apart, set them in 'Enabled character set', to reset just select a lesson

Keep sessions short until you build up stanima.

Don't type more than one character for each sent, if you type the wrong character, move on to the next one

If you catch yourself thinking before recognizig a character, except when first learning the character, it means you need to keep learning that character. To make sure you do, increase the 'Word WPM'. To challenge yourself you should still timeout every so often.

Roll back the 'Koch enabled' and 'Lesson' when starting a new session to review the last characters you learned before learning any new characters.

Under 'Settings', 'Reset' controls how long after starting before morse starts and extra time whenever you miss a character to regain your composure
